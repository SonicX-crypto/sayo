# Установка Sayo

## Обычная установка из DMG

1. На странице [Releases](https://github.com/SonicX-crypto/sayo/releases/latest)
   скачайте DMG и `SHA256SUMS.txt` одной версии.
2. При желании проверьте загрузку:

   ```sh
   shasum -a 256 ~/Downloads/Sayo-*-macOS-arm64.dmg
   ```

   Результат должен совпасть со строкой для DMG в `SHA256SUMS.txt`.
3. Откройте DMG и дважды нажмите `Install Sayo Components.command`.
4. Если Homebrew ещё не установлен, скрипт покажет официальный адрес
   [brew.sh](https://brew.sh/ru/). Установите Homebrew и повторите шаг 3.
5. Перетащите `Sayo.app` на ярлык `Applications`.
6. Запустите Sayo. Для текущей ненотаризированной preview-сборки может потребоваться
   `Системные настройки` → `Конфиденциальность и безопасность` → `Всё равно открыть`.

Не отключайте Gatekeeper целиком и не выполняйте случайные команды обхода защиты.

## Разрешения macOS

Sayo попросит два разрешения:

- `Микрофон` — для записи голоса;
- `Универсальный доступ` — для глобального правого `⌘` и автоматической вставки.

Если правый `⌘` не реагирует, откройте `Системные настройки` → `Конфиденциальность и
безопасность` → `Универсальный доступ`, включите Sayo и перезапустите приложение.
Статусы разрешений видны в меню Sayo.

## Ручная установка компонентов

В клонированном репозитории выполните:

```sh
./scripts/setup-dependencies.sh
```

Эквивалентные отдельные шаги:

```sh
brew install ffmpeg whisper-cpp
./scripts/download-model.sh
```

Загрузку модели можно безопасно продолжить после обрыва: используется временный файл
с расширением `.part`. Готовый файл принимается только после проверки SHA-256.

## Своя модель

Sayo принимает модели GGML, поддерживаемые установленной версией whisper.cpp:

```sh
defaults write ru.specit.RightCommandDictation modelPath -string "/полный/путь/model.bin"
```

Путь должен быть абсолютным. После команды перезапустите приложение. Сбросить выбор:

```sh
defaults delete ru.specit.RightCommandDictation modelPath
```

Порядок автоматического поиска:

1. путь из `modelPath`;
2. `~/Library/Application Support/Sayo/Models/ggml-large-v2.bin`;
3. `~/Library/Application Support/superwhisper/ggml-large.bin`.

## Удаление

Закройте Sayo и переместите `/Applications/Sayo.app` в Корзину. При необходимости
отдельно удалите локальные данные:

```text
~/Library/Application Support/Sayo
```

Модель занимает большую часть места. Удаление этой папки также удалит сохранённые после
ошибок аудиозаписи, поэтому сначала проверьте каталог `Recovery`.
