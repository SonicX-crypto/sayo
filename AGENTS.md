# Инструкции для работы над Sayo

Перед изменениями прочитайте `PROJECT.md`, `README.md`, `docs/ARCHITECTURE.md` и
`.planning/ROADMAP.md`.

## Границы проекта

- Это самостоятельный macOS-проект. Не переносите его обратно в `spec-it`.
- Не изменяйте и не удаляйте файлы Superwhisper. Модель используется только для чтения.
- Не добавляйте `ggml-large.bin`, записи пользователя, `.build` или `dist` в Git.
- Сохраняйте bundle ID `ru.specit.RightCommandDictation` и стабильный путь
  `/Applications/Sayo.app`. Ребрендинг в Sayo утверждён 22 июля 2026 года.
- Локальный сервер должен слушать только `127.0.0.1`.

## Сборка и проверка

```sh
./build-app.sh
codesign --verify --deep --strict --verbose=2 "dist/Sayo.app"
plutil -lint "dist/Sayo.app/Contents/Info.plist"
```

Для установки используйте `./install-app.sh`. После замены подписанной локально сборки
проверьте правый `⌘`, микрофон, вставку, HUD и процесс `whisper-server` без флага `-ng`.
Пользователь 22 июля 2026 года разрешил после проверенных production-изменений всегда
самостоятельно устанавливать и активировать Sayo без отдельного подтверждения. Это не
отменяет отдельный preview-цикл для ещё не утверждённых визуальных экспериментов.

## Важные технические факты

- На M4 Pro Metal работает корректно вне sandbox и существенно быстрее CPU.
- Падение GPU-CLI, замеченное в начале разработки, воспроизводилось внутри ограниченной
  среды запуска, а не в установленном приложении.
- SwiftPM конфликтует с текущей парой Command Line Tools/SDK, поэтому `build-app.sh`
  вызывает `swiftc` напрямую с macOS 15.4 SDK.
- Глобальная клавиша и автоматическая вставка требуют Accessibility/TCC.
- Микрофон требует `NSMicrophoneUsageDescription` и отдельного разрешения.
