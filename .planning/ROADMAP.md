# Roadmap Sayo

Связанные направления с подробным контекстом для следующих сессий:

- [PRODUCT_DIRECTION.md](PRODUCT_DIRECTION.md) — продуктовая стратегия и приоритеты
  глазами основателя;
- [DESIGN_DIRECTION.md](DESIGN_DIRECTION.md) — дизайн орбиты, темы и критерии готовности.

## Ближайшие этапы — выполнять по одному

- [x] Этап 1. Упростить цветовой блок: собственный цвет через picker/HEX/RGB и три
  рекомендованных цвета, раскрываемых только по нажатию `Цвет по умолчанию`.
- [ ] Этап 2. Оптимизировать и подключить готовую тему «Природа», проверить все
  состояния орбиты в 80–128 pt и показать отдельный preview.
- [x] Этап 3. Отдельно оптимизировать и подключить «Маскота», сначала проверив
  читаемость глаз, волны и силуэта в 80–96 pt; реакцию выражения на голос не добавлять
  автоматически без отдельного решения.
- [ ] Этап 4. Сделать `Свои обои…`: drag-and-drop/выбор файла, круглый preview,
  масштабирование и кадрирование, рекомендация `1024×1024 px, PNG или JPEG`,
  копируемая подсказка для нейросети, замена, удаление и возврат к стандартной теме.
- [ ] Этап 5. Провести общую accessibility/несколько экранов/HDR-проверку тем.
- [x] Этап 6. После явного визуального утверждения перенести решения в production HUD;
  установку выполнять только по отдельной команде пользователя.

Каждый этап завершается самостоятельным preview и обратной связью пользователя. Не
объединять этапы ради одной большой реализации и не помечать следующий этап выполненным
до проверки предыдущего.

## P0 — надёжность

- [x] встроенная диагностика разрешений микрофона и Accessibility;
- [x] health-check, автоматический перезапуск и резервный режим при недоступном порте
  18080;
- [x] защита от слишком коротких и пустых записей;
- [x] сохранение и повторное распознавание записи после локального сбоя;
- [x] запрет неявной ad-hoc подписи при сборке и установке;
- проверка нескольких микрофонов и переключения аудиоустройства во время записи.

## P1 — скорость и качество жизни

- автоостановка после настраиваемой паузы;
- [x] отображение RMS-уровня микрофона в HUD;
- настройка визуального диапазона: спокойное дыхание в тишине сохраняется, но реакция
  на речь должна однозначно отличаться от паузы;
- состояние «нет входного сигнала» только при подтверждённой проблеме аудиоустройства,
  без ложной ошибки во время обычной тишины;
- запуск при входе в macOS;
- настройка звуков начала и завершения;
- выбор языка: авто, русский, английский.

## P2 — качество текста

- персональный словарь имён, брендов и терминов через initial prompt;
- режимы «дословно», «чистый текст», «деловой стиль», «перевод»;
- локальная постобработка небольшой LLM без отправки текста в облако;
- пользовательские правила пунктуации и форматирования.

## P3 — продуктовая упаковка

- [x] отдельное окно настроек HUD, доступное из menu bar;
- минималистичная настройка цвета: собственный цвет через picker/HEX/RGB и скрытые до
  нажатия три рекомендованных варианта `Цвета по умолчанию`;
- подключить тему «Природа»; `Космос` и `Маскот` уже работают в production;
- отдельная панель `Свои обои…`: drag-and-drop/выбор файла, круглый preview,
  масштабирование и кадрирование, рекомендация `1024×1024 px, PNG или JPEG`, готовая
  подсказка для нейросети и безопасный сброс;
- onboarding разрешений;
- выбор любой клавиши или сочетания, проверка конфликтов и динамическая подсказка в HUD;
- [x] naming-этап: утверждено `Sayo` (`say` + `O`, орбита), bundle ID сохранён;
- подписанная notarized-сборка;
- автоматические обновления;
- [x] полноценный ребрендинг приложения в Sayo со стабильной локальной подписью.
