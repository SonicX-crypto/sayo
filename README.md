# Sayo

Локальная голосовая диктовка для macOS. Название соединяет `say` («говорить») и `O`
(орбиту): правый `⌘` начинает и останавливает запись,
Whisper Large распознаёт речь на Metal GPU, после чего текст сохраняется в буфер обмена
и автоматически вставляется в активное поле.

Аудио и текст не отправляются в интернет. Приложение использует уже установленную модель:

`~/Library/Application Support/superwhisper/ggml-large.bin`

## Возможности

- глобальная клавиша — правый `⌘`;
- полная Whisper Large-модель без снижения качества;
- ускорение через Metal на Apple Silicon;
- светлый HUD «живая орбита», который пульсирует от уровня голоса;
- темы орбиты `Стандартная`, `Космос` и `Маскот` с сохранением выбора;
- встроенное окно настройки HUD: орбита или постоянная капсула, цвета состояний,
  размер, материал, реакция на голос, уменьшение движения и повышенный контраст;
- единая выбранная форма для записи, Metal-обработки и результата;
- выбранная форма не меняется от наведения: орбита всегда остаётся орбитой, капсула —
  капсулой;
- HUD перетаскивается мышью и запоминает положение;
- `Esc` отменяет запись;
- автоматическая вставка отключается из меню;
- локальная история 12 последних фраз;
- постоянный локальный сервер модели на `127.0.0.1:18080` с проверкой готовности и
  автоматическим перезапуском;
- локальное восстановление записи после ошибки распознавания или аварийного завершения.

Окно персонализации открывается через значок Sayo в строке меню →
`Настроить HUD…` (или `⌘,`). Все рабочие параметры сохраняются автоматически.

## Сборка

```sh
cd /Users/dmitrijovcinnikov/Projects/vox-command
./build-app.sh
```

Готовая сборка появится в `dist/Sayo.app`.

Обычная сборка требует стабильную локальную identity `VoxCommand Local Development` и
останавливается, если она недоступна. Только для отдельной неустанавливаемой проверки
можно явно разрешить ad-hoc подпись:

```sh
SAYO_ALLOW_ADHOC_SIGNING=1 ./build-app.sh
```

## Установка обновления

```sh
./install-app.sh
```

Скрипт собирает приложение, обновляет `/Applications/Sayo.app`, удаляет прежнюю копию
`/Applications/Локальная диктовка.app` и запускает Sayo. Если в Keychain установлен
сертификат `VoxCommand Local Development`, сборка
использует стабильную локальную подпись и сохраняет выданные разрешения между обновлениями.
Если сертификат или его закрытый ключ недоступен, установка прекращается до остановки и
замены работающего приложения. Ad-hoc сборка никогда не устанавливается этим скриптом.

Если распознавание не удалось, исходная запись остаётся только локально в
`~/Library/Application Support/Sayo/Recovery`. В menu bar появляется команда
`Повторить сохранённую запись`; после успеха файл удаляется автоматически.

## Зависимости на текущем Mac

- macOS 26, Apple M4 Pro;
- Swift / Command Line Tools;
- `/opt/homebrew/bin/whisper-server` и `whisper-cli`;
- `/usr/local/bin/ffmpeg` или `/opt/homebrew/bin/ffmpeg`;
- модель `ggml-large.bin` размером около 3,1 ГБ.

Модель не копируется внутрь репозитория или `.app`.
