# Sayo — память проекта

Обновлено: 22 июля 2026 года.

## Замысел

Sayo — быстрая приватная диктовка для macOS, которая работает полностью локально
и ощущается как нативная функция системы. Основной сценарий: поставить курсор, нажать
правый `⌘`, сказать текст, нажать правый `⌘` снова и получить готовый текст в поле и
буфере обмена.

## Текущее состояние

Рабочая версия 0.5.0 (build 7) установлена и активна в `/Applications/Sayo.app`.

Реализовано:

- запись через `AVAudioEngine`;
- глобальный перехват правого Command через `CGEventTap`;
- конвертация записи в WAV 16 кГц с помощью ffmpeg;
- Whisper Large через постоянный `whisper-server`;
- Metal GPU на M4 Pro без замены или квантования модели;
- автovставка через буфер обмена и синтетический `⌘V`;
- перетаскиваемый HUD с сохранением координат в `UserDefaults`;
- светлый динамический HUD «живая орбита» с реакцией на громкость микрофона;
- production-темы `Стандартная`, `Космос` и `Маскот`, выбираемые в menu bar;
- встроенная персонализация HUD с сохранением формы, материала, цветов, размера,
  реакции на голос и accessibility-параметров;
- фирменная иконка Sayo с маскотом, голосовой волной и орбитой;
- история 12 последних расшифровок;
- отмена записи через `Esc`;
- menu bar-интерфейс и фирменная иконка;
- раздельная диагностика Accessibility и Input Monitoring;
- очередь локального восстановления неудачных записей без потери сказанного;
- health-check и автоматический перезапуск локального Whisper-сервера;
- безопасная остановка сборки и установки при отсутствии стабильной подписи.

## Проверенные показатели

На тестовом аудио полный Whisper Large через CPU тратил примерно 4,5–5 секунд только
на основной проход. Metal GPU обработал тот же файл за 0,83–1,18 секунды. Веса модели и
параметры декодирования не менялись, поэтому ускорение не связано с потерей качества.

После утверждённого ребрендинга путь изменён с `/Applications/Локальная диктовка.app`
на `/Applications/Sayo.app`. Bundle ID сохранён, чтобы designated requirement и
выданные разрешения macOS оставались стабильными.

Проверка Keychain вне ограниченной среды подтвердила прежнюю действующую identity с тем
же корневым отпечатком, который записан в designated requirement установленной Sayo.
Поэтому следующие сборки можно обновлять без смены code requirement и повторной выдачи
TCC-разрешений.

Сборка использует стабильный локальный сертификат. Это предотвращает смену designated
requirement при каждом обновлении и повторный сброс Accessibility/TCC. `build-app.sh`
больше не переходит на ad-hoc подпись автоматически: тестовый режим включается только
явным `SAYO_ALLOW_ADHOC_SIGNING=1`, а `install-app.sh` в любом случае требует стабильную
identity. Во время дизайн-итераций собирать отдельный preview напрямую через `swiftc`,
не подписывать и не устанавливать приложение после каждого изменения.

Установку и активацию новой production-сборки выполнять только по отдельной команде
пользователя. Разрешение установить 0.5.0 относилось только к этой конкретной версии и
не является постоянным разрешением для будущих изменений.

## Продуктовые принципы

1. Локальность по умолчанию: аудио и расшифровки не уходят в сеть.
2. Один жест для основного сценария.
3. Полезная обратная связь без захвата фокуса.
4. Качество важнее искусственных benchmark-ускорений.
5. Все настройки должны иметь безопасные значения по умолчанию.
