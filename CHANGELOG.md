# Changelog

- Metal GPU для полной Whisper Large-модели;
- новый стеклянный HUD со статусами `REC`, `LOCAL`, `ГОТОВО`;
- перетаскивание HUD и сохранение положения;

- отмена записи клавишей `Esc`;
- фирменная иконка;
- стабильная установка в `/Applications`.
